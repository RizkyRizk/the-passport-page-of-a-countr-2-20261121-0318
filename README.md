A pure-stdlib Python program that draws one invented passport spread
for the Republic of Veskara, a mountain republic whose lanterns never
go out. The left page is the data page: portrait, holder details,
signature, and a machine-readable zone. The right page carries a
Kaldor entry visa, three stamps with a consistent travel history
(all after the 14 MAR 2024 issue date), a lantern-tax fee stamp,
and a condition of stay that reveals what kind of place Veskara is.

## Run

```sh
python3 main.py   # writes /output/entry.png (1024x1024 PNG, deterministic)
```

No network, no third-party libraries — the Python standard library only.
